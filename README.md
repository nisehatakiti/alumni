# 高校同窓会サイト / Alumni WordPress Project

高校同窓会組織向けのWordPressテーマ＋プラグイン企画。

## プロジェクトの方向性

古い「お知らせを並べるだけ」の同窓会サイトを、現代的で更新しやすく、卒業生・在校生・学校をゆるくつなぐWebサイトへ再設計する。

最初は**高校同窓会に特化**して企画・試作する。将来的な大学同窓会・OB会等への展開は、初期設計を壊さない範囲で考慮する。

## 基本方針

- **テーマと機能を分離**する
  - テーマ：見た目、レイアウト、ページ構成、ブランド表現
  - プラグイン：データ、投稿フロー、承認、会員・連絡先管理など
- WordPressを基盤として、用途別テーマと再利用可能なプラグインを組み合わせる。
- 最初から巨大なSaaSを作らず、WordPressの既存機能を最大限利用する。
- 架空の高校「**偽秦高等学校**」をデモ校として、実際のサイトを作りながら仕様を固める。

## 卒業生インタビュー構想

### 投稿の入口
サイト上に一般公開の入口を設け、たまたま同窓会サイトを訪れた卒業生でも投稿できるようにする。

### 投稿時に収集する情報
**本人確認・管理用（原則非公開）**
- 姓名
- 旧姓（任意）
- メールアドレス（必須）
- 卒業年
- クラス
- 部活動
- 必要に応じてその他在学時情報

**公開候補情報**
- 表示名（実名 / 名前のみ / イニシャル / 匿名）
- 卒業後の進路
- 現在の職業・業界
- 進路を選んだきっかけ
- 学生時代にやっておけばよかったこと
- 学生時代にやっておいて良かったこと
- 在校生へのメッセージ
- 写真（任意）

### 公開フロー
1. 卒業生がフォームから投稿
2. 投稿は即時公開せず、審査待ち / 下書きとして保存
3. 同窓会組織側が卒業生本人であることを確認
4. 内容と公開範囲を確認
5. 承認後に記事として公開

### 個人情報・公開範囲
- 本人確認用の氏名・メールアドレス等と、公開用情報を分離する。
- 公開する氏名・卒業年・写真等は投稿時に本人が選択できるようにする。
- 公開後も本人からの申請で修正・非公開・削除できる仕組みを用意する。

### 継続更新
投稿日と最終更新日 / 最終確認日を保持する。
年1回程度、投稿者へメールで「内容を更新しますか / このまま掲載しますか / 掲載を終了しますか」を確認する。

メールアドレスはインタビュー確認・更新連絡のため必須とするが、一般的なメルマガ配信への同意とは分ける。

## メールマガジン構想

サイト更新を会報代わりに活用する。

- Web記事をメールマガジンで案内
- 新着情報、活動報告、総会案内、母校NEWS等を配信
- 「一度記事を書けばサイト＋メールで利用できる」更新導線を目指す
- 将来的には購読者管理と配信履歴をプラグイン側で扱う

## 卒業生データベース構想

投稿時に卒業年・クラス・部活動などを取得し、同窓会内部で検索・集計できるようにする。

将来的な用途：
- 同期会への連絡
- 部活OB/OGへの案内
- 卒業年度別の情報整理
- 卒業生インタビューの検索・絞り込み

部活動やクラスは自由入力だけにせず、同窓会ごとのマスタを持たせる方向で検討する。

## 在校生とのコミュニケーション構想

同窓会を「卒業生が昔を懐かしむサイト」だけにせず、在校生にとっても価値のある場所にする。

主なアイデア：
- 卒業生の進路ストーリー
- 「先輩に聞く」Q&A
- 卒業生の仕事・キャリア紹介
- 学生時代にやっておけばよかったこと等の経験共有

個人名や勤務先を必ず公開するのではなく、在校生が知りたい「進路のパターン」「仕事の実態」「先輩の経験」に重点を置く。

## 卒業生の店舗・サービス（将来拡張）

卒業生が経営 / 運営する飲食店や事業者を紹介し、卒業生向け特典を提供できる仕組みを検討する。

例：
- 卒業生経営の飲食店
- 美容・士業・医療・地域サービス等
- 卒業生限定割引 / サービス

まずは高校同窓会で需要を確認し、初期版では必須機能にしない。

## デモ校

**偽秦高等学校 同窓会**

コンセプト例：
> つながる。語る。次の世代へ。

デモサイトでは「同窓会が何をしている組織なのか」が一目で伝わることを重視する。

## トップページの方向性

従来の「新着情報の羅列」から脱却し、次の順序を基本案とする。

1. ヒーロー / 同窓会のメッセージ
2. 同窓会の活動内容
3. 新着情報
4. 卒業生の、その後
5. 同窓会活動レポート
6. 母校の今
7. 会報 / 支部・同期会 / 会員向け導線

## 商材としての方向性

まずは**高校同窓会向けのWordPressテーマ＋専用プラグイン**として考える。

想定する価値：
- 古くなった同窓会サイトを現代的に再構築
- 更新を簡単にする
- 同窓会活動を分かりやすく伝える
- 卒業生から自然にコンテンツと連絡先情報を集める
- Web会報＋メールで継続的に情報発信する

将来的には大学同窓会・OB会等への横展開を想定するが、当面の企画・試作は高校同窓会に集中する。

## 開発の進め方

まずは実際のデモサイトを作りながら、テーマとプラグインの境界を整理する。

### Phase 1
- 偽秦高等学校のサイト構成
- トップページ
- 同窓会について / 沿革 / 会長挨拶 / 校長挨拶 / 校歌
- 新着情報 / 活動報告
- 卒業生インタビューの見せ方

### Phase 2
- 卒業生インタビュー投稿フォーム
- 承認フロー
- 公開範囲設定
- メールアドレス管理
- 卒業年 / クラス / 部活動等の属性

### Phase 3
- 年1回の更新確認
- メールマガジン
- 会報アーカイブ
- 卒業生データベースの検索・集計

### Phase 4
- 卒業生の店舗・サービス紹介
- 卒業生特典
- 在校生との交流機能の拡張
