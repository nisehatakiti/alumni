# 高校同窓会サイト / Alumni WordPress Project

高校同窓会組織向けのWordPressテーマ＋プラグイン企画。

## プロジェクトの方向性

古い「お知らせを並べるだけ」の同窓会サイトを、現代的で更新しやすく、卒業生・在校生・学校をゆるくつなぐWebサイトへ再設計する。

最初は**高校同窓会に特化**して企画・試作する。将来的な大学同窓会・OB会等への展開は、初期設計を壊さない範囲で考慮する。

## 基本方針

- **テーマと機能を分離**する
  - テーマ：見た目、レイアウト、ページ構成、ブランド表現
  - プラグイン：データ、投稿フロー、承認、会員・連絡先管理など
- WordPressを基盤として、用途別テーマと再利用可能なプラグインを組み合わせる。
- 架空の高校「**偽秦高等学校**」をデモ校として、実際のサイトを作りながら仕様を固める。

## デモ校

**偽秦高等学校 同窓会**

コンセプト例：
> つながる。語る。次の世代へ。

## コンテンツとデータ構造

### 会長挨拶【独立投稿】
- 会長氏名
- 役職名
- 挨拶本文
- 写真
- 更新日

### 母校校長挨拶【独立投稿】
- 校長氏名
- 役職名
- 挨拶本文
- 写真
- 更新日

### 沿革【専用フォーム / 専用データ】
入力項目：
- 年月
- 事柄

同じ沿革データをテーマ側でタイムライン・年表などとして表示できるようにする。

### 校歌【専用フォーム】
校歌は通常の投稿本文に混在させず、専用フォームとして管理する。

登録項目：
- 校歌のタイトル
- 歌詞
- 音源
- 楽譜

音源・楽譜はWordPressメディアライブラリから登録できる形を想定する。テーマ側では、歌詞表示・音源プレイヤー・楽譜へのリンクまたは表示をそれぞれ独立して扱えるようにする。

### 卒業期早見表【自動生成機能】
生まれ年から、卒業年度と何期生かを確認できる機能。

初期設定として、少なくとも以下を設定する。
- 第1期生の卒業年
- 第1期生の基準となる生まれ年

現在年を基準に一覧を自動生成し、毎年新しい年度が自動的に追加される。新しい年を上に表示する。

表示例：
| 生まれ年 | 卒業年 | 期生 |
|---|---|---|
| 2007年 | 2026年 | 第○期 |
| 2006年 | 2025年 | 第○期 |

将来的には「生まれ年を選ぶと自分が何期生か分かる」検索機能も検討する。

### 卒業生インタビュー【独立プラグイン機能】
卒業生からの声はテーマ必須機能ではなく、プラグインを有効化した場合に利用できる機能とする。

投稿者は公開フォームから入力するが、即時公開はしない。

1. 卒業生がフォームから投稿
2. 下書き / 審査待ちとして保存
3. 管理者が本人確認と内容確認
4. 管理者が編集・投稿
5. 承認後に公開

写真は任意。写真がある場合とない場合でテーマ側がレイアウトを調整できるようにする。

### イベント情報【専用投稿】
最低限の入力項目：
- 日付
- タイトル
- 内容

必要に応じて場所、申込方法、締切などを追加できる。

### お知らせ【専用投稿】
入力項目：
- タイトル
- 自由形式の本文
- 公開日

### 新着情報【統合表示】
イベント情報とお知らせを、それぞれ別に管理しつつ、トップページ等では「新着情報」として日付順に統合表示する。

例：
- 2026.08.20［イベント］同窓会総会を開催します
- 2026.08.18［お知らせ］ホームページをリニューアルしました

## トップページ構成

### ヘッダー / ブランド表示
- 学校の校章
- 同窓会独自のロゴ（存在する場合）
- 「○○高等学校同窓会」の名称

基本イメージ：
`[ 校章 ]   偽秦高等学校同窓会   [ 同窓会ロゴ ]`

### トップページ全体メッセージ【自由入力欄】
トップページには、管理者が自由に入力できる**全体メッセージ欄**を設ける。

用途：
- 同窓会全体からのメッセージ
- 周年記念メッセージ
- サイトリニューアル時の告知
- 卒業生への呼びかけ
- キャッチコピーや短い文章

通常の投稿ではなく、トップページ設定画面から自由に編集できるフィールドとする。ヒーローエリアまたはブランド表示直下など、テーマのデザインに応じた位置へ表示する。

### 基本セクション
1. ヘッダー / 校章・同窓会ロゴ・同窓会名称
2. 全体メッセージ（自由入力）
3. 新着情報（イベント＋お知らせの統合）
4. 同窓会会長挨拶
5. 母校校長挨拶
6. 母校ニュース
7. 同窓会ニュース
8. 沿革
9. 卒業生からの声（プラグイン有効時のみ表示）

## 卒業生インタビュー構想

### 本人確認・管理用（原則非公開）
- 姓名
- 旧姓（任意）
- メールアドレス（必須）
- 卒業年
- クラス
- 部活動

### 公開候補情報
- 表示名
- 卒業後の進路
- 現在の職業・業界
- 進路を選んだきっかけ
- 学生時代にやっておけばよかったこと
- 学生時代にやっておいて良かったこと
- 在校生へのメッセージ
- 写真（任意）

### 継続更新
投稿日と最終更新日 / 最終確認日を保持する。
年1回程度、投稿者へメールで内容確認・更新・掲載終了の選択を案内する。

## メールマガジン構想

- Web記事をメールマガジンで案内
- 新着情報、活動報告、総会案内、母校NEWS等を配信
- 「一度記事を書けばサイト＋メールで利用できる」更新導線を目指す

## 卒業生データベース構想

卒業年・クラス・部活動などを取得し、将来的に同期会や部活OB/OGへの案内、卒業生インタビューの検索・絞り込みに活用する。
