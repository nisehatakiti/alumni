# トップページ レイアウト設計原則

## 基本方針

コンテンツの管理と、トップページ上での配置・見せ方を分離する。

- プラグイン／投稿側：コンテンツそのものを管理する
- テーマ側：コンテンツをどこに、どの順番で、どのレイアウトで表示するかを管理する

トップページの利用者は、個別の投稿データを再入力することなく、定型レイアウトを選択して構成を変更できる。

## コンテンツブロック方式

トップページは複数のコンテンツブロックで構成する。

例：

1. 全体メッセージ
2. 新着情報
3. 会長挨拶・校長挨拶
4. 母校ニュース
5. 同窓会ニュース
6. Alumni Voices
7. Teacher's Voice
8. 沿革・周年情報等

各ブロックは、表示ON/OFFおよび表示順を設定できる。

## 複数コンテンツをまとめたレイアウト

会長挨拶をA、校長挨拶をBとした場合、テーマ側で以下のような定型パターンを選択可能とする。

### 横並び A｜B

Aを左、Bを右に表示する。

### 横並び B｜A

Bを左、Aを右に表示する。

### 縦並び A→B

Aを上、Bを下に表示する。

### 縦並び B→A

Bを上、Aを下に表示する。

必要に応じて、将来的に左右の比率を変更する定型パターンを追加可能とする。

例：

- A：大／B：小
- A：小／B：大

## 管理画面の考え方

ドラッグ＆ドロップで完全自由にページを組み立てる独自ページビルダーはMVPでは作成しない。

理由：

- 実装規模が大きくなる
- テーマの保守が複雑になる
- 利用者がレイアウト設計で迷う
- 同窓会広報担当の作業負荷を増やす可能性がある

代わりに、各ブロックについて以下を設定する。

```text
表示：ON / OFF
表示順：数値または順序選択
レイアウト：定型パターンから選択
```

## 設計原則

「自由度を最大化する」のではなく、「迷わず選べる自由度を提供する」。

コンテンツは一度登録すれば、テーマ側の設定によって複数の見せ方を選択できる。

この方式により、広報担当はHTMLやCSSを触ることなく、学校・同窓会ごとの事情に合わせたトップページ構成を選択できる。
