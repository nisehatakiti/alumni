# トップページ：スロットベースのレイアウト設計

## 1. 方針

トップページは、個別コンテンツの組み合わせを固定してレイアウトする方式ではなく、テーマがあらかじめ定義した「配置スロット」に対して、管理者が表示コンテンツを割り当てる方式を採用する。

コンテンツとレイアウトを完全に分離する。

```text
テーマ
  └── ページ構造・配置スロット

管理者設定
  └── 各スロットに表示するコンテンツを選択

プラグイン／投稿
  └── コンテンツそのものを管理
```

## 2. スロット例

テーマ側で、例えば以下の構造を定義する。

```text
┌──────────────────────┐
│         HERO         │
└──────────────────────┘

┌───────────┬───────────┐
│     A     │     B     │
└───────────┴───────────┘

┌──────────────────────┐
│          C           │
└──────────────────────┘

┌───────┬────────────────┐
│   D   │       E        │
└───────┴────────────────┘
```

管理者は A〜E の各スロットにコンテンツを割り当てる。

例：

```text
A：会長挨拶
B：校長挨拶
C：新着情報
D：Alumni Voices
E：母校ニュース
```

別の学校では同じレイアウトのまま、以下のように変更できる。

```text
A：Teacher's Voice
B：Alumni Voices
C：母校ニュース
D：会長挨拶
E：同窓会ニュース
```

## 3. テーマごとのレイアウト

各テーマは独自のページ構造を持つ。

### Classic

```text
HERO
↓
A｜B
↓
C
↓
D｜E
```

### Magazine

```text
HERO
↓
A
↓
B｜C
↓
D
```

### Community

```text
HERO
↓
A｜B｜C
↓
D
```

スロットの数・サイズ・配置はテーマが決定する。

## 4. 管理画面

テーマ設定画面では、各スロットについて表示コンテンツを選択する。

```text
トップページ設定

HERO
[ 全体メッセージ ▼ ]

A
[ 会長挨拶 ▼ ]

B
[ 校長挨拶 ▼ ]

C
[ 新着情報 ▼ ]
```

必要に応じて、コンテンツごとの表示件数や見出しも設定可能とする。

## 5. コンテンツ候補

MVPでは、以下をスロットに割り当て可能なコンテンツ候補とする。

- 全体メッセージ
- 新着情報
- 会長挨拶
- 校長挨拶
- 沿革
- 母校ニュース
- 同窓会ニュース
- イベント情報
- Alumni Voices
- Teacher's Voice
- 同窓会活動報告
- 卒業期早見表
- 同窓会組織図
- 理事・役員一覧
- 校歌

テーマによって適した表示形式が異なる場合は、そのテーマで対応可能なコンテンツだけを候補として表示してもよい。

## 6. 設計原則

管理者にページビルダーのような完全自由な配置作業を要求しない。

```text
× ドラッグ＆ドロップで自由にレイアウト
× 任意の場所に任意のサイズで配置
```

ではなく、

```text
○ デザインされたテーマを選択
○ 用意されたスロットにコンテンツを選択して差し込む
```

方式とする。

これにより、デザイン品質を保ちながら、学校・同窓会ごとの優先情報に合わせてトップページを変更できる。

## 7. 最終原則

> コンテンツは自由に選べるが、レイアウトはテーマが美しく制御する。

本プロダクトの目的である「広報担当が楽をしながらホームページを活性化する」を維持するため、自由度と簡単さのバランスを優先する。
