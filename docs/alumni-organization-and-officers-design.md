# 同窓会組織図・理事／役員一覧 設計

## 1. 目的

同窓会の組織構成と、現在の理事・役員をホームページ上で分かりやすく公開・管理する。

単なる固定ページではなく、役職変更や任期交代が発生しても WordPress 管理画面から更新できる構造とする。

## 2. 公開コンテンツ

### 同窓会組織図

例：

```
総会
 │
 ├── 会長
 │    │
 │    ├── 副会長
 │    ├── 事務局
 │    ├── 総務
 │    ├── 会計
 │    ├── 広報
 │    └── 各種委員会
 │
 └── 監査
```

組織ごとに構成が異なるため、固定HTMLではなく、管理画面から組織・部署・委員会を追加できる設計とする。

### 理事・役員一覧

公開例：

```
会長　　山田 太郎
副会長　佐藤 花子
理事　　鈴木 一郎
理事　　高橋 次郎
監査　　田中 三郎
```

氏名の公開範囲は同窓会ごとに設定できるようにする。

## 3. データ構造

役職そのものと、役職に就いている人物を分離する。

### organization_positions

役職・組織上のポジションを管理する。

```
id
name
parent_id
position_type
sort_order
status
created_at
updated_at
```

例：

```
会長
副会長
理事
監査
事務局長
会計担当
広報担当
```

`parent_id` により組織図の階層を表現する。

### officer_assignments

役職への就任情報を管理する。

```
id
position_id
alumni_id
name_override
term_start
term_end
is_public
sort_order
status
created_at
updated_at
```

原則として `alumni_id` で Alumni Core の卒業生情報と紐付ける。

ただし、名簿に登録されていない人物や、公開上の表記を変えたい場合のため `name_override` を用意する。

## 4. Alumni Core との関係

理事・役員が卒業生の場合：

```
officer_assignments
      │
      └── alumni_id
             │
             ▼
        Alumni Core
```

これにより、役員の卒業期等を内部的に把握できる。

ただし公開画面では、本人の同意がない限り卒業年やメールアドレス等の個人情報を表示しない。

## 5. WordPress 管理画面

独立した管理メニューを用意する。

```
同窓会組織
├── 組織図
├── 理事・役員一覧
├── 役職管理
└── 設定
```

### 組織図管理

- 組織・委員会・役職の追加
- 親組織の設定
- 並び順変更
- 公開／非公開

### 理事・役員一覧管理

- Alumni Core から卒業生を検索
- 役職を選択
- 任期開始日
- 任期終了日
- 公開／非公開
- 表示順

## 6. 任期管理

役員は毎年・数年ごとに交代するため、履歴を残す。

```
2024/04/01 ～ 2026/03/31
会長
山田 太郎

2026/04/01 ～
会長
佐藤 花子
```

公開画面では現在有効な役員を自動表示する。

過去役員一覧は、必要に応じて公開できる。

## 7. 組織図の表示方法

テーマ側でレイアウトを自由に変更できるよう、データと表示を分離する。

想定表示：

- 縦型ツリー
- 横型組織図
- カード型
- スマートフォン向け階層リスト

プラグインは組織構造のデータを提供し、最終的なデザインはテーマ側が担当する。

## 8. ホームページ上の配置

トップページでは組織図を常時大きく表示する必要はない。

以下の独立ページを想定する。

```
同窓会について
├── 同窓会長挨拶
├── 同窓会組織図
└── 理事・役員一覧
```

必要に応じてトップページからリンクする。

## 9. 初期リリース範囲

MVPでは以下を実装する。

- 役職マスタ管理
- 組織階層管理
- 卒業生との役員紐付け
- 任期開始・終了
- 現役役員の自動抽出
- 公開／非公開
- 組織図データ出力
- 理事・役員一覧データ出力

ドラッグ＆ドロップ式の高度な組織図エディタや、歴代役員アーカイブの高度な表示は将来拡張とする。

## 10. 設計原則

組織図と理事・役員一覧は、単なる固定ページではなく、同窓会組織の構造と人事情報を管理するデータとして扱う。

ただし Alumni Core の名簿管理とは責務を分離し、組織管理機能は役職・任期・組織階層を担当する。

表示デザインはテーマ側に寄せる。
