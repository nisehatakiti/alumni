# 汎用フォームエンジン

Alumni Core 内の汎用フォーム機能は、将来単独の WordPress プラグインとして切り出せることを前提に、以下の4クラスへ閉じ込めています。

- `class-post-type.php`
- `class-meta-box.php`
- `class-public.php`
- `class-module.php`

## 現在の機能

- フォームを Custom Post Type として管理
- 公開URLと `[alumni_form id="..."]` ショートコード
- テキスト、メール、電話、数値、テキストエリア、セレクト、ラジオ、チェックボックス
- ファイル添付
- 項目ごとの必須設定
- テキスト系項目ごとの最小文字数・最大文字数
- ファイル項目ごとの許可拡張子・最大ファイルサイズ
- ブラウザ側の HTML バリデーション
- サーバー側の再検証
- WordPress MIME/拡張子検証
- メール送信時の添付
- 送信後の一時アップロードファイル削除

## 独立プラグイン化方針

Alumni 固有の依存を公開フォーム処理から排除し、フォーム CPT のメニュー親だけを
`alumni_forms_menu_parent` フィルターで差し替え可能にしています。

独立版では次の変更だけで切り出せる構成です。

1. 4クラスを独立プラグインへ移動
2. 独立したプラグインヘッダーとローダーを追加
3. `alumni_forms_menu_parent` のデフォルトを WordPress のトップレベルまたは `true` にする
4. テキストドメインを独立版の名称へ変更
5. 必要に応じて CPT スラッグとメタキーを移行

データモデルと公開フォームの処理は Alumni Core の他機能に依存しないため、
将来的な単独プラグイン化で機能ロジックを書き直す必要がないことを目標としています。


## フィールドレイアウト設定

各フィールドは表示幅と改行位置を個別に設定できます。

- 幅: 25 / 33 / 50 / 66 / 75 / 100 %
- 「この項目の後で改行」を有効にすると、短い項目でも次の項目を必ず新しい行から開始
- 同一行では、合計幅が 100% を超えない範囲で横並び

## 複数行テキストの高さ

`textarea` フィールドは表示行数を 2〜50 行で設定できます。初期値は 4 行です。
これは文字数制限とは独立した表示上の高さ設定です。

## メールアドレス確認

メールアドレスフィールドでは「確認用入力欄を表示する」を有効にできます。

- 公開フォームに確認用メールアドレス欄を追加
- 確認用ラベルは個別指定可能。未指定時は「元のラベル（確認）」を使用
- 送信時にサーバー側でも一致確認を実施
- 確認用入力値はメール本文には含めない
